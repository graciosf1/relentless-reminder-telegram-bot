# 🔔 Checkpoint Reminder Bot

Строгий Telegram-бот для управления задачами и напоминаниями с защитой от прокрастинации. 

Если задачу не отметить вовремя, бот запускает цепочку учащающихся чекпоинтов. Отложить дело можно только один раз и строго с указанием причины.

---

## ✨ Основные фичи

- **Механический парсинг времени:** понимает команды вроде `15м Помыть посуду`, `19:00 Тренировка`, `25.12 10:00 Сдать отчет`.
- **Эскалация чекпоинтов:** напоминает о задаче с сокращающимся интервалом (15 → 10 → 5 → 2 → 1 мин), пока она не будет закрыта.
- **Осознанный перенос:** перенести дело можно только 1 раз, обязательно указав причину и новое время.
- **Геймификация:** отправляет случайную победную GIF за каждое выполненное действие.
- **Итоги дня:** ровно в 23:00 присылает красивую сводку закрытых задач за день (или по команде `/summary`).

---

## 🛠 Стек технологий

- **Python 3.10+**
- **aiogram 3.x** — асинхронный фреймворк для Telegram Bot API
- **APScheduler** — планировщик периодических и отложенных задач
